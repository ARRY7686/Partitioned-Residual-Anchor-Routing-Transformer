# TMLR submission draft

`main.tex` is the paper in the official TMLR style (`tmlr.sty`, `tmlr.bst`, `fancyhdr.sty` and
`math_commands.tex` from github.com/JmlrOrg/tmlr-style-file; the untouched template is in
`template/`). It compiles anonymously by default; `\usepackage[preprint]{tmlr}` shows the author
for arXiv, `\usepackage[accepted]{tmlr}` is for the camera-ready version.

To build on Overleaf, upload this folder (`main.tex`, `refs.bib`, the four style files and
`figures/`). Before submitting: replace the anonymous code link placeholder, check that the main
text stays within 12 pages, and keep the author block hidden.

The earlier LNCS draft for IRIS'27 is in `../paper/`. All numbers come from
`../experiments/RESULTS_SUMMARY.md`.
